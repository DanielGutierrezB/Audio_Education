Processing Pipeline

1

Probe

FFprobe reads basic format metadata (duration, sample rate, channels). No further analysis — processing decisions are fixed, not adapted per file.

2

Measure

Runs the file through mono mixdown + EQ + loudnorm in measurement mode and parses the JSON summary — integrated loudness (LUFS), true peak (dBFS), loudness range (LRA), gating threshold. These values feed the render pass for a single linear-gain normalisation.

3

Render

Mono mixdown → resample (only if source isn't at target rate) → EQ chain (HPF, mud, box, honk, presence, air) → loudnorm in linear mode using measured stats to land on −16 LUFS integrated with TP ≤ −2 dBTP. Sources already at or above −16 LUFS skip the loudnorm step entirely. Output: WAV 24-bit 48 kHz in Audio_Pro/.

4

EQ editor

Open the EQ tab, pick a source file from the dropdown, hit Play and drag bands in real time. Every band change auto-saves — when you go back to Processing and hit Process All, the pipeline uses whatever curve the editor is currently showing. Reset returns to the base EQ; Bypass A/Bs the preview without touching the saved state.
