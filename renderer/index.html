AudioPro v0.3.0

The best version of the voice — from the raw take, from Adobe Podcast, or from both.

🔗 Fuse Mode 2 only · original + Adobe 100%

Two entry modes

1

Mode 1 · Original only

Drop the raw recording with no Adobe Podcast step. AudioPro analyzes it, applies conditional local denoise (RNNoise) only when the measured noise floor calls for it, repairs whatever the detectors actually flag (clipping, hum, clicks, silence padding), then runs the shared tone/dynamics/loudness chain below.

2

Mode 2 · Original + Adobe Podcast 100%

Drop a folder containing the raw recordings and an Enhanced/ subfolder (the convention adobe-podcast-batch writes when "Voz limpia" is left at 100%). AudioPro pairs each file by name automatically, fuses the two signals to the ideal balance — by default, low end from the original, mids/highs from the enhanced track — and continues from that best-of-both starting point.

Shared processing chain

1

Analyze

A read-only FFmpeg pass measures loudness (I/LRA/TP), spectral rolloff, band energies (body/mud/presence/sibilance/air/hum) and silence edges, and turns them into QC flags — shown as chips next to each file. Nothing is changed unless a flag actually fires.

2

Clean + repair (conditional)

Mode 1 only: RNNoise denoise gated by the measured noise floor, scaled to how far over threshold it is. Both modes: hum notches, click removal, de-clip, and head/tail silence trim — each one only inserted into the chain when its detector fired, so already-clean material renders bit-for-bit through the same path untouched.

3

Tone + Dynamics

HPF → EQ cuts (mud/box/honk) → gentle leveling compression (skipped if the source is already dense) → optional parallel "body" compression → presence/air boosts (air shelf skips automatically on band-limited sources) → dynamic de-esser (only engages on measured sibilance).

4

Loudness + verify

Two-pass loudnorm to the selected delivery preset (Platzi / YouTube / Podcast — see the toolbar selector), a true-peak safety limiter always at the very end, then a fast re-measure of the rendered file to confirm it landed on target.

5

EQ editor

Open the EQ tab, pick a source file from the dropdown, hit Play and drag bands in real time. Every band change auto-saves — when you go back to Processing and hit Process All, the pipeline uses whatever curve the editor is currently showing. Reset returns to the base EQ; Bypass A/Bs the preview without touching the saved state.
