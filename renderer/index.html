Three entry paths

1

Mode 1 · Original only

Drop the raw recording with no Adobe Podcast step. AudioPro analyzes it, applies conditional local denoise (RNNoise) only when the measured noise floor calls for it, repairs whatever the detectors actually flag (clipping, hum, silence padding — plus an unconditional, safe de-click pass since mouth clicks have no reliable detector), then runs the shared tone/dynamics/loudness chain below.

2

Mode 2 · Original + Adobe Podcast 100%

Drop a folder containing the raw recordings and an Enhanced/ subfolder — written by the embedded Enhance below, or by a manual run of adobe-podcast-batch with "Voz limpia" at 100%. AudioPro pairs each file by name automatically, fuses the two signals to the ideal balance — by default, low end from the original, mids/highs from the enhanced track — and continues from that best-of-both starting point.

3

Embedded Enhance · the whole process in one click

Turn on Enhance with Adobe in Settings, connect your Adobe account once (the session is stored encrypted and refreshes silently), and drop just the raw takes. Process Selection uploads each unpaired file to Adobe Podcast Enhance Speech — 5 in parallel, pausing with a countdown when credits run out and resuming on its own — saves the 100% clean voice to Enhanced/ next to the original (plus an optional Enhanced/Mix N/ dry/wet blend at the "Clean voice mix" percentage), then continues as Mode 2. Originals are never modified, and files that already have an Enhanced/ pair never re-upload, so no credits are spent twice.

Shared processing chain

1

Analyze

A read-only FFmpeg pass measures loudness (I/LRA/TP), spectral rolloff, band energies (body/mud/presence/sibilance/air/hum) and silence edges, and turns them into QC flags — shown as chips next to each file. Nothing is changed unless a flag actually fires.

2

Clean + repair (conditional)

Mode 1 only: RNNoise denoise gated by the measured noise floor, scaled to how far over threshold it is. Both modes: hum notches, de-clip, and head/tail silence trim — each one only inserted into the chain when its detector fired, so already-clean material skips them entirely. De-click is the one exception: there's no reliable detector for mouth clicks, so it runs on every file with safe, conservative defaults rather than waiting on a detector that doesn't exist yet.

3

Tone + Dynamics

HPF → EQ cuts (mud/box/honk) → gentle leveling compression (skipped if the source is already dense) → optional parallel "body" compression → presence/air boosts (air shelf skips automatically on band-limited sources) → optional harmonic exciter ("Presence extra", off by default) → dynamic de-esser (only engages on measured sibilance).

4

Loudness + verify

Two-pass loudnorm to the selected delivery preset (Platzi / YouTube / Podcast — see the toolbar selector), a true-peak safety limiter always at the very end, then a fast re-measure of the rendered file to confirm it landed on target.

5

EQ editor

Open the EQ tab, pick a source file from the dropdown, hit Play and drag bands in real time (shift-click a band to disable it, scroll to change its Q). Every band change auto-saves — when you go back to Processing and hit Process Selection, the pipeline uses whatever curve the editor is currently showing. Reset returns to the base EQ; Bypass A/Bs the preview level-matched to the current curve (a make-up gain measured on that file’s own spectrum cancels the average loudness the EQ adds, so the A/B judges tone, not volume). Mode 2 pairs add an Original / Enhanced / Fusion switch to compare the three raw candidate signals — each one still plays through the same live EQ curve you're editing, so you're choosing the best starting point, not toggling the EQ on and off.

6

QC tools

Right-click any queued file for a spectrogram — hum shows as a solid horizontal line, clipping as bright full-band smears, denoise artefacts as speckle in what should be silence. The document icon in the toolbar exports a Markdown QC report for the whole batch (mode, flags, output loudness check per file) to attach to the course deliverable.
